### 1.2 注释规范执行情况

- 全部 24 个新建 .c/.h 采用 **UTF-8 without BOM** 编码（`file` 命令验证）。
- 注释统一 `//`（C99 风格），全项目零 `/* */`（含 include guard 的 `#endif` 行尾标签）。
- 文件头含 `@file/@brief/@author/@date/@version` 五要素；对外函数用 `@brief/@param/@return` 结构化标签。
- 每个宏注明物理含义/取值/单位；全局变量与 ISR 内 static 计数器、`dis_code`、`DIG_CODE` 均注明用途与取值范围。
- 代码注释只描述代码自身的 What/Why，不包含任何重构背景、妥协原因或工具配置提示——此类内容全部归入本文档。

## 3. 妥协与特殊处理清单（2026-09-03 已全部处理，对照见 8.2；原文保留为历史记录）

### 3.1 BSP/HAL 包含 APP/app_tasks.h（分层妥协）

`mode/temper/last_time/led_flag/play_flag/temp_flag` 六个全局业务状态被定时器 ISR 直接读写（`Timer1_ISR` 读 `mode/last_time`；`Timer0_ISR` 递减 `last_time`；`Timer2_ISR` 置位 `led_flag/temp_flag`；ISR 与主循环无参数传递通道）。由于重构禁止修改任何函数实现，无法引入回调注册或参数注入，故 `bsp_pwm.c`、`hal_timer.c` 直接包含 `APP/app_tasks.h` 访问 extern 声明。因此《项目结构规范》中 hal_timer 的"中断回调注册"与 soft_timer 的"替代静态计数"两项要求未实施——二者均需改动 ISR 实现，与功能冻结约束冲突。

### 3.2 `set()` 调用搬迁（消除 BSP→Service 逆向依赖）

原 `display()` 首行调用 `set()`（BSP 层调用 Service 层，逆向）。现改为 `HAL/hal_timer.c` 的 `Timer2_ISR()` 末尾依次调用：

```c
set();
display();
```

调用时序不变：中断内先刷新显示缓冲、再执行扫描，每 1ms 一次，行为等价。这是唯一一处影响函数体的搬线，已通过冻结比对确认（`display()` 差异恰为删除的 `set();` 行，`Timer2_ISR` 差异恰为新增的 `set();` 行）。

### 3.3 未创建的规范文件

- `HAL/hal_gpio.*`：Backup 无对应代码，规范标注"若需要"则不建。
- `Service/soft_timer.*`：规范的软定时器需替换 ISR 内静态计数器实现，属改实现，被功能冻结禁止。

## 6. 已知保留项（2026-09-03 已修正，见 8.5；原文保留为历史记录）

`Service/temp_sensor.c` 的 `Read_Tempe()` 中以下两行与 Backup 原实现逐字一致、原样保留：

```c
temp = high & 0x0f;
temp = temp << 8 | low;
```

该写法对正温度、高字节 < 16 时结果正确；与教科书式的 `temp = (high << 8) | low` 存在差异（负温度与高字节 ≥ 16 时行为不同）。因"绝对不调整功能及其实现"约束，本次未做任何修改；如需修正应在后续功能变更中单独处理。

## 8. 2026-09-03 第二轮调整：Read_Tempe 修正与分层规范落实

### 8.1 调整范围

1. **Read_Tempe() 修正**：原 `high & 0x0f` 拼接改为完整 16 位拼接并按补码还原符号（bit15），负温返回负值；`temper` 由 `uchar` 升为 `int`；温度页负温显示 `'-'` + 绝对值（格式与正温前导零一致，如 `-05`）。

### 8.3 行为等价性依据

| 原版 | 新版 | 依据 |
|---|---|---|
| Timer0_ISR：t_1ms 第 999 次触发递减 last_time | soft_timer 倒计时通道（period=999，定时器2 节拍）回调递减 | 触发周期同为 999ms；Timer0/Timer2 同为 1ms 时基，节拍源替换抖动 <20µs，不可辨 |
| Timer2_ISR：i/j 第 200/537 次触发置 led_flag/temp_flag | soft_timer LED/温度通道（period=200/537）回调置位 | 触发 tick 序号相同 |
| Timer2_ISR 每 ms 调 set()+display() | App_TickHandler 每 ms：SoftTimer_Tick → dirty 渲染 → display() | 缓冲内容仅在状态变化时改变；状态变化后 ≤1ms（1 个节拍）渲染并扫描，含按键按住期间（Read_Key 阻塞主循环时渲染不受影响） |
| last_time 归零 → Timer1 下一 20µs tick 停转 | 倒计时回调内（中断上下文）立即 `PWM_Control(mode,0)` | 停转不晚于原版 |
| 按键改 mode/last_time → Timer1 下一 tick 生效 | 按键后主循环 `App_Commit()` 推送，早于下一 20µs tick | 等效 |
| PWM 波形（k 计数/阈值 9/14/33/47/复位） | 逐字保留，仅读 pwm_mode/pwm_run | 波形一致 |
| 负温：无符号放大错误 | 补码还原 + 负号显示 | 本轮修正点 |
| 正温 0~125℃ 换算 | raw 拼接值与原式相等（high≤0x07 时 `high & 0x0f == high`） | 逐位相同 |
